# Penguin AI Center

**Connect AI assistants to your Windows PC and get real work done.**

Penguin AI Center connects compatible AI assistants to your authorized Windows devices and project workspaces through the Model Context Protocol (MCP).

Use natural-language requests to work with local files, develop and test code, manage website projects, and perform supported browser and desktop tasks.

## Core Features

- **AI-powered development** — Read, edit, and test code in authorized project folders.
- **Local task execution** — Run supported tasks through the Penguin AI Center Windows Connector.
- **Browser integration** — Connect supported browser workflows through the Penguin browser extension.
- **Permission controls** — Manage access to devices, folders, and capabilities.
- **Task tracking and recovery** — Track execution results and resume supported workflows after interruptions.

## Getting Started

1. Install the Penguin AI Center Windows Connector.
2. Sign in and configure your device and workspace permissions.
3. Connect a compatible AI assistant through MCP.
4. Install the browser extension if you need browser integration.
5. Describe your task and let your AI assistant use the authorized tools.

## Availability

Available features depend on your product version, subscription, permissions, and the capabilities of your connected AI assistant.

An AI assistant account or subscription may be required separately.
